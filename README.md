# SmartBuy Guide — free affiliate website starter

This is a responsive static website starter for an Amazon Associates product-recommendation business.

## Files
- `index.html` — page structure and starter content
- `styles.css` — responsive corporate styling
- `script.js` — mobile navigation and starter interactions

## Before publishing
1. Confirm the Amazon Associates program you are using and read its current operating agreement and website requirements.
2. Replace the placeholder product sections with researched, accurate recommendations.
3. Replace the placeholder product buttons in `index.html` with your own eligible Amazon Associates links. Do not use someone else's tracking ID.
4. Add a real contact email and any other required site information.
5. Keep the affiliate disclosure visible. The current page includes: “As an Amazon Associate I earn from qualifying purchases.”
6. Only use product images and Amazon pricing/availability data in ways permitted by Amazon's current policies. Do not copy images or customer reviews without permission.
7. Do not claim personal product testing unless you actually tested the product. Keep comparisons honest and up to date.

## Free hosting option: GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new public repository, for example `smartbuy-guide`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
4. Open repository **Settings → Pages**.
5. Under the build/deployment section, choose deploy from a branch, select `main` and `/ (root)`, then save.
6. GitHub will show the published website address after deployment.

A free hosted address is fine to start; a custom domain is optional and normally costs money. You do not need to buy hosting for GitHub Pages.

## Important
This bundle is a starter website, not a registered Amazon Associates account and not a source of affiliate links. The product buttons intentionally do not send visitors to Amazon until you add your own links.
